## 数码荔枝的优惠只有这几种，网上那些“优惠码”多是转述

新用户入会后送一次首单立减，满 29 减 2 和满 39 减 5 二选一。补差价订单和特惠购商品不能用这张券。

每月优惠券在每月 1 日 0 点按你当月的初始等级发放，当个月内有效，一个月只能领一次。就算你这个月消费升级到了更高等级，也不能再领一张更高等级的，要等次月刷新。

特惠购是会员专区的特价商品，定价低于日常售价，清单不定期更新。买特惠购商品不能用优惠券、优惠码和首单立减，但订单金额会计入累计消费，也会照常产生积分。

还有一条容易踩空的：在数码荔枝淘宝店下单不产生积分，商业采购也不走站内这套优惠。想用会员券，就得在荔枝商店站内下单。

## 下单前在页面上核对这几项，比省 5 块钱重要

改名工具这个品类里，名字相近的产品在 Windows 和 macOS 上各有好几款，功能描述看着差不多，授权规则差别很大。商品页上有几项得自己看清楚：

- 适用的操作系统和最低系统版本。
- 授权能激活几台设备。
- 是单用户授权，还是允许多人共用。
- 永久授权，还是按年订阅。
- 大版本能否免费升级。这条最容易被跳过，工具换代以后旧授权覆不覆盖新版本，各家做法不一样。
- 激活方式：发激活码，还是需要绑定账号。
- 是否提供发票，价格含不含税。

页面上没写清楚的，先别付钱。分销商的客服能帮你确认订单和激活，但不会替你判断这款软件适不适合你的工作流。

## 常见问题

**数码荔枝有通用优惠码吗？**
没有可以公开分发的通用码。折扣都走会员体系，大头是首单立减和每月优惠券，特惠购价与积分兑换券算补充，全部绑在你的账号上。

**首单立减和每月优惠券能一起用吗？**
不能。规则写明每月优惠券无法与其他优惠券或营销优惠权益叠加，一次只能用一张。

**买了能退吗？**
数字化商品不适用七天无理由。只有官方条款列明的少数情形能在 7 个自然日内申请，下单前先把条款过一遍。

**数码荔枝是软件开发商吗？**
不是，是授权分销商。多家开发商在自家官网公示过它的代理身份。软件本身的功能和版本节奏由开发商决定。

**特惠购里的价格是不是最低？**
不一定。特惠购不能用券，得拿它和你手上的券后价比一比，哪个低算哪个。
